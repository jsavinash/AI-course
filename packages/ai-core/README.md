# ai-core

Shared AI/ML foundation library for the monorepo.

## Modules

- `config` - 12-factor config loader
- `logging` - Structured JSON logging
- `metrics` - Prometheus metrics base
- `registry` - MLflow model registry
- `validation` - Schema validation
- `drift` - Data/concept drift detection
- `layers` - Neural network layer primitives
- `losses` - Common loss functions
- `optim` - Optimizer implementations
- `train_loop` - Generic training loop with callbacks
- `api_base` - FastAPI base app with middleware
