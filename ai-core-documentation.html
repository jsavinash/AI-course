Overview & Monorepo Context

Package Identity

Name: ai-core (importable as ai_core)
Location: packages/ai-core/ within a broader AI monorepo.
Purpose: The foundational MLOps shared library — the single source of truth for cross-cutting concerns that every other package in the monorepo depends on.

Role in the Monorepo

Every production ML service in the repository consumes ai-core for:

  • Configuration — unified, hierarchical config with 12-factor-app env-var overrides, YAML files, nested dataclass sections, type coercion, and automatic secrets redaction.
  • Structured Logging — structlog-based JSON logging with per-request correlation IDs (request ID & trace ID via ContextVar), sensitive-key redaction, and optional rotating file handlers.
  • Prometheus Metrics — singleton MetricsCollector that registers and exposes Counter, Gauge, and Histogram metrics on a configurable HTTP endpoint.
  • Model Registry — filesystem-backed model artifact store with lifecycle stage management (staging → production → archived) and optional MLflow integration.
  • Data Validation — schema-driven validation of NumPy arrays and Pandas DataFrames with range checks, type enforcement, NaN/Inf detection, and per-feature statistics.
  • Drift Detection — statistical drift monitoring using Kolmogorov-Smirnov (continuous), Chi-Squared (categorical), and Population Stability Index (PSI) tests.
  • FastAPI Middleware — plug-and-play observability middleware for request logging, latency measurement, and security headers.
  • Neural-Net Primitives — minimal NumPy-based implementations of Conv2D, MaxPool2D, Dense, Activation, SimpleCNN, and SimpleRNN layer classes for educational and lightweight use cases.

The Mathematical Foundation

2.1 Configuration — Type Coercion

No statistical model, but the coercion rules define a discrete type-transformation algebra over the set of environment-variable strings:

Type Coercion Rules bool : s ∈ {"true","1","yes","on"} → True, else False int : int(s) float : float(s) Path : Path(s) List : [v.strip() for v in s.split(",") if v.strip()] Dict : json.loads(s)

2.2 Drift Detection — Kolmogorov-Smirnov Test

The KS two-sample test compares the empirical cumulative distribution functions (ECDFs) of the reference and current samples for a continuous feature. The test statistic is the maximum distance between the two ECDFs:

KS Test Statistic D = sup_x | F_ref(x) − F_cur(x) | The p-value is computed from the Kolmogorov distribution: p = Q_KS( √(n_ref · n_cur / (n_ref + n_cur)) · D ) where Q_KS is the complementary CDF of the Kolmogorov distribution. Drift is flagged when p < α (default α = 0.05).

The KS test is non-parametric — it makes no assumption about the underlying distribution shape, making it robust for general-purpose drift detection. It is sensitive to differences in both location (mean shift) and shape (variance change).

2.3 Drift Detection — Chi-Squared Test (Categorical)

For binary or categorical features, the chi-squared goodness-of-fit test compares observed category frequencies against the reference distribution:

Chi-Squared Statistic χ² = Σᵢ (Oᵢ − Eᵢ)² / Eᵢ where Oᵢ is the observed count in category i (current data) Eᵢ is the expected count under the reference distribution p-value ~ χ²(k−1) where k = number of categories.

Drift is flagged when p < α or when the PSI (see below) exceeds 0.2.

2.4 Drift Detection — Population Stability Index (PSI)

PSI quantifies the total divergence between two probability distributions and is widely used in credit-risk and MLOps monitoring. It is computed by binning the reference distribution and comparing bin proportions:

Population Stability Index (Continuous) PSI = Σⱼ ( (Cur_j − Ref_j) · ln(Cur_j / Ref_j) ) where Ref_j and Cur_j are the proportions of samples in bin j for the reference and current distributions respectively. Bins are defined as percentiles of the reference distribution: bin_j = [ percentile(ref, (j−1)/n_bins·100) , percentile(ref, j/n_bins·100) ] with edge bins extended to (−∞, +∞) to avoid missing values. For categorical data: PSI = Σₖ ( (cur_propsₖ − ref_propsₖ) · ln(cur_propsₖ / ref_propsₖ) )

PSI Interpretation:

  • PSI < 0.10 → No significant drift
  • 0.10 ≤ PSI < 0.20 → Moderate drift (investigation recommended)
  • PSI ≥ 0.20 → Significant drift (action required) — this is the psi_threshold default.

PSI was chosen over KL divergence because it is symmetric in the limit and more interpretable in industry practice. Small proportion values are clipped to 1e-6 to prevent log(0) singularities.

2.5 Metrics — Percentile Calculation

Latency percentiles (P95, P99) are computed from an in-memory sorted list of recorded durations:

Empirical Percentile P_p = sorted_latencies[ floor( N · p/100 ) ] where N = len(sorted_latencies), clamped to [0, N−1].

This is the nearest-rank method, an O(N log N) exact computation suitable for the modest sample sizes typical of inference metrics. It is preferred over interpolation because it guarantees the returned value exists in the dataset.

2.6 Neural Networks — He Initialization

Conv2D weights are initialized using He (Kaiming) initialization, which preserves variance through ReLU-activated layers:

He Initialization W ~ N(0, 2 / (n_in)) where n_in = in_channels · kernel_size · kernel_size Applied as: W = randn(out_channels, in_channels, k, k) · √(2 / n_in)

Why He instead of Xavier? He initialization is designed for ReLU activations (which zero out ~50% of neurons). Xavier/Glorot initialization uses a variance of 1/n_in, which is half of what He uses, and would cause signal attenuation through ReLU layers. He initialization doubles the variance to compensate, resulting in stable gradient flow during training.

2.7 Neural Networks — ReLU, Sigmoid, and Tanh Activations

Activation Functions ReLU: f(x) = max(0, x) Sigmoid: f(x) = 1 / (1 + e^(−x)) Tanh: f(x) = (eˣ − e^(−x)) / (eˣ + e^(−x)) Softmax (RNN output): softmax(x)ᵢ = e^(xᵢ − max(x)) / Σⱼ e^(xⱼ − max(x)) (The max-subtraction is a numerically stable trick that prevents overflow.)

2.8 Neural Networks — Transposed Convolution (Deconv2D)

The Deconv2D.forward() implements transposed convolution for upsampling:

Output Spatial Dimensions H_out = (H_in − 1) · stride + kernel_size W_out = (W_in − 1) · stride + kernel_size Each input pixel x[n,c_in,h,w] is multiplied by the filter kernel W[c_in,c_out] and added to the corresponding output region starting at (h·stride, w·stride).

This is the mathematical transpose of the standard convolution operation — instead of sliding a kernel over the input and summing, each input value spreads its contribution across a kernel_size × kernel_size region in the output. Used for decoder paths in autoencoders and generative models.

2.9 Model Registry — Version Promotion Logic

The promotion algorithm ensures at most one production model exists at any time, implemented as an atomic reclassify operation:

Promote to Production ∀ m ∈ Registry: if m.status == "production" → m.status = "archived" target.status = "production" Allowed transitions (state machine): staging → {production, archived} production → {archived, staging} archived → {staging} champion → {candidate, archived} candidate → {champion, archived}

Core Logic & Architecture

3.1 High-Level Data Flow

An MLOps service bootstraps itself in this order:

Bootstrap Sequence 1. load_config() → Resolves Config from YAML + env vars 2. setup_logging() → Configures structlog with JSON output + redaction 3. MetricsCollector() → Creates singleton Prometheus metrics (or retrieves existing) 4. start_metrics_server() → Exposes /metrics on configured port 5. ModelRegistry() → Initializes filesystem-backed model store (optionally connects MLflow) 6. DriftDetector() → Pre-loads reference statistics for drift comparison 7. add_observability_middleware() → Wires FastAPI with logging + metrics + security headers

3.2 Configuration Layer

Uses a layered override pattern: defaults → YAML → env vars. Env vars take the highest priority. Nested config sections are loaded independently using a prefixed env-var namespace (e.g. MLOPS_MONITORING_DRIFT_THRESHOLD overrides monitoring.drift_threshold).

Key design decisions:

  • BaseConfig is a dataclass with from_env, from_yaml, from_dict, to_dict, to_yaml, to_json, and validate class/instance methods — a complete bidirectional serialization protocol.
  • SENSITIVE_KEYS is a constant set used by _redact() to mask passwords, tokens, and API keys in all serialized output.
  • Config.load() (class method) performs the three-stage merge atomically and re-loads nested sections from env to guarantee that env vars always win, even after YAML loading.

3.3 Logging Layer

Built on structlog with a processor chain:

structlog Processor Pipeline merge_contextvars → add_log_level → StackInfoRenderer → TimeStamper(iso, utc=True) → _add_context → _redact_event_dict → JSONRenderer | ConsoleRenderer

Context propagation uses Python's ContextVar — this is async-safe and thread-safe without any explicit locking, because each asyncio task or OS thread gets its own independent copy of the variable.

3.4 Metrics Layer

The MetricsCollector implements the Flyweight / Singleton pattern per service name. Prometheus client libraries require that metric names be registered exactly once; the singleton ensures that even if multiple modules instantiate MetricsCollector("my-service"), only one set of underlying Counter/Gauge/Histogram objects is created.

3.5 Model Registry

The registry is a directory-tree-backed key-value store with a strict lifecycle state machine. Each model version lives at {base_dir}/{model_name}/{model_version}/ with a model_info.json metadata file and arbitrary artifact files.

Version retention policy: The _enforce_max_versions() method keeps only the N most recently modified versions (default N=5). Production models are never auto-archived, protecting the live serving artifact.

3.6 Drift Detection

The DriftDetector dispatches to a strategy based on feature type:

  • Continuous features → KS two-sample test + PSI on equal-frequency bins.
  • Binary / Categorical features → Chi-squared goodness-of-fit test + categorical PSI.

The combined drift_score takes the maximum of the normalized KS statistic and the PSI, ensuring that either test alone is sufficient to flag drift. This conservative strategy minimizes false negatives at the cost of slightly higher false-positive rate.

3.7 FastAPI Middleware

Two Starlette middleware classes wrap every request:

  • RequestLoggingMiddleware — generates/correlates request IDs, measures wall-clock latency, records Prometheus metrics, logs structured events, and injects X-Request-ID into the response header.
  • SecurityHeadersMiddleware — adds OWASP-recommended security headers (X-Content-Type-Options, X-Frame-Options, Strict-Transport-Security, etc.) to every response.

3.8 Neural Network Utilities

The nn_utils sub-package provides a layer-composition architecture inspired by Keras but implemented in pure NumPy. Each layer implements a uniform interface:

Layer Interface forward(x) → output tensor backward(grad) → input gradient (for chain rule) update_params(lr, weight_decay) → applies gradient descent step

SimpleCNN and SimpleRNN orchestrate these layers in a list, running forward() in order and backward() in reverse (autodiff via manual chain rule).

SENSITIVE_KEYS = {"password", "secret", "token", "api_key", "apikey", "credential"}

def _redact(value: Any, key: str = "") -> Any:
    # Recursively walk dicts/lists and mask any key containing a sensitive substring.
    # This prevents credential leakage when config.to_dict() / .to_json() is logged.
    if any(s in key.lower() for s in SENSITIVE_KEYS):
        return "***REDACTED***"
    if isinstance(value, dict):
        return {k: _redact(v, k) for k, v in value.items()}
    if isinstance(value, list):
        return [_redact(v) for v in value]
    return value

class BaseConfig:
    """Base configuration with env var support."""

    @classmethod
    def from_env(cls: type[T], prefix: str = "") -> T:
        # Walk every dataclass field; look up PREFIX_FIELD_NAME in os.environ.
        # If found, coerce the string value to the field's annotated type.
        type_hints = get_type_hints(cls)
        kwargs: dict[str, Any] = {}
        for f in fields(cls):
            env_key = f"{prefix}_{f.name.upper()}" if prefix else f.name.upper()
            env_val = os.getenv(env_key)
            if env_val is not None:
                kwargs[f.name] = _coerce_value(env_val, type_hints.get(f.name, f.type))
        return cls(**kwargs)

        config.mlflow      = MLflowConfig.from_env(f"{prefix}_MLFLOW")
        config.registry    = ModelRegistryConfig.from_env(f"{prefix}_REGISTRY")
        config.monitoring  = MonitoringConfig.from_env(f"{prefix}_MONITORING")
        config.data        = DataConfig.from_env(f"{prefix}_DATA")
        return config

def setup_logging(level="INFO", json_output=True, log_file: Path | None = None, ...):
    # 1. Clear existing handlers (idempotent setup)
    root_logger = logging.getLogger()
    root_logger.setLevel(log_level)
    for handler in root_logger.handlers[:]:
        root_logger.removeHandler(handler)

    # 2. Always add console handler
    console_handler = logging.StreamHandler(sys.stdout)
    root_logger.addHandler(console_handler)

    # 3. Optionally add rotating file handler
    if log_file:
        file_handler = logging.handlers.RotatingFileHandler(
            log_file, maxBytes=max_bytes, backupCount=backup_count, encoding="utf-8"
        )
        root_logger.addHandler(file_handler)

    # 4. Wire the structlog processor chain
    processors = [
        structlog.contextvars.merge_contextvars,   # bring ContextVar values into event dict
        structlog.processors.add_log_level,
        structlog.processors.StackInfoRenderer(),
        structlog.processors.TimeStamper(fmt="iso", utc=True),
        _add_context,                               # inject request_id / trace_id
        _redact_event_dict,                          # mask secrets
    ]
    processors.append(
        structlog.processors.JSONRenderer() if json_output
        else structlog.dev.ConsoleRenderer()
    )
    structlog.configure(
        processors=processors,
        wrapper_class=structlog.make_filtering_bound_logger(log_level),
        logger_factory=structlog.PrintLoggerFactory(),
        cache_logger_on_first_use=True,
    )

    def __new__(cls, service_name: str, port: int = 8000) -> MetricsCollector:
        # __new__ intercepts object creation BEFORE __init__ runs.
        # If this service_name was already instantiated, return the cached object.
        if service_name not in _instances:
            instance = super().__new__(cls)
            _instances[service_name] = instance
        return _instances[service_name]

    def __init__(self, service_name: str, port: int = 8000):
        # __init__ is called EVERY time, so guard with _initialized to skip re-registration.
        if not hasattr(self, "_initialized"):
            self.service_name = service_name
            self.prediction_counter = Counter(

                f"Total number of predictions for {service_name}",
                ["model_version"],
            )
            # ... 8 more metrics registered here ...
            self._initialized = True

Why the dual guard (__new__ + __init__)? Prometheus Counter/Gauge registration is global and raises ValueError on duplicate names. The __new__ guard returns the same Python object across all callers, but Python still calls __init__ on the returned object unless we intercept at __new__ and skip it. The hasattr(self, "_initialized") pattern is the standard idiom for making __init__ idempotent.

4.5 drift.py — Statistical Drift Detection Engine

src/ai_core/drift.pyPythondef _detect_continuous_drift(self, name, ref, cur) -> DriftResult:
    # 1. Kolmogorov-Smirnov two-sample test (non-parametric)
    ks_stat, ks_pvalue = stats.ks_2samp(ref, cur)

    # 2. Population Stability Index (equal-frequency binning on reference)
    psi = self._compute_psi(ref, cur)

    # 3. Combined drift score = max(KS statistic, PSI)
    #    Conservative: either metric exceeding its threshold flags drift.
    drift_score = max(ks_stat, psi)
    is_drift = ks_pvalue < self.ks_threshold or psi > self.psi_threshold

    return DriftResult(feature_name=name, drift_score=drift_score,
                         p_value=ks_pvalue, is_drift=is_drift, ...)

def _compute_psi(self, ref, cur, n_bins=10) -> float:
    # Equal-frequency binning based on reference distribution percentiles
    bins = np.percentile(ref, np.linspace(0, 100, n_bins + 1))
    bins[0] = -np.inf    # catch values below min reference
    bins[-1] = np.inf   # catch values above max reference

    ref_hist, _ = np.histogram(ref, bins=bins)
    cur_hist, _ = np.histogram(cur, bins=bins)
    ref_props = ref_hist / len(ref)
    cur_props = cur_hist / len(cur)
    return self._compute_psi_categorical(ref_props, cur_props)

def _compute_psi_categorical(self, ref_props, cur_props) -> float:
    # Clip to avoid log(0); PSI is undefined at zero probability
    ref_props = np.clip(ref_props, 1e-6, 1.0)
    cur_props = np.clip(cur_props, 1e-6, 1.0)
    return float(np.sum((cur_props - ref_props) * np.log(cur_props / ref_props)))

    def __init__(self, **kwargs):
        self.in_channels  = kwargs.get("in_channels", 1)
        self.out_channels = kwargs.get("out_channels", 8)
        self.kernel_size  = kwargs.get("kernel_size", 3)

            self.kernel_size, self.kernel_size

Deconv2D — Transposed Convolution Forward Pass

src/ai_core/nn_utils/cnn.py (Deconv2D)Pythonclass Deconv2D:
    def forward(self, x: np.ndarray) -> np.ndarray:
        N, C_in, H_in, W_in = x.shape
        # Output dimensions for transposed convolution with stride s and kernel k:
        H_out = (H_in - 1) * self.stride + self.kernel_size
        W_out = (W_in - 1) * self.stride + self.kernel_size
        out = np.zeros((N, self.out_channels, H_out, W_out))

        # Each input value spreads across a kernel-sized region in the output
        for n in range(N):
            for c_out in range(self.out_channels):
                for c_in in range(C_in):
                    for h_in in range(H_in):
                        for w_in in range(W_in):
                            h_start = h_in * self.stride
                            w_start = w_in * self.stride
                            region = out[n, c_out, h_start:h_start+k, w_start:w_start+k]
                            region += x[n, c_in, h_in, w_in] * self.W[c_in, c_out]
        out += self.b.reshape(1, -1, 1, 1)
        return out

Activation — ReLU, Sigmoid, Tanh

src/ai_core/nn_utils/cnn.py (Activation)Pythonclass Activation:
    def __init__(self, name: str = "relu", **kwargs):
        self.name = name

    def forward(self, x: np.ndarray) -> np.ndarray:
        if self.name == "relu":
            return np.maximum(0, x)           # f(x) = max(0, x)
        elif self.name == "sigmoid":
            return 1.0 / (1.0 + np.exp(-x))  # f(x) = 1/(1+e^(-x))
        elif self.name == "tanh":
            return np.tanh(x)                  # f(x) = (e^x - e^(-x))/(e^x + e^(-x))
        return x

4.8 nn_utils/rnn.py — Simple RNN

src/ai_core/nn_utils/rnn.pyPythondef softmax(x: np.ndarray) -> np.ndarray:
    # Numerically stable softmax: subtract max before exponentiation to prevent overflow.
    e_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return e_x / e_x.sum(axis=-1, keepdims=True)

@dataclass
class SimpleRNN:
    # Weight matrices
    Wxh: np.ndarray   # (hidden_size, input_size)  — input-to-hidden
    Whh: np.ndarray   # (hidden_size, hidden_size) — hidden-to-hidden (recurrent)
    Why: np.ndarray   # (output_size, hidden_size) — hidden-to-output
    bh: np.ndarray    # (hidden_size, 1)  — hidden bias
    by: np.ndarray    # (output_size, 1)  — output bias

    def __post_init__(self) -> None:
        # __post_init__ runs AFTER the dataclass-generated __init__.
        # It allows us to initialize weight matrices with correct dimensions
        # even though input_dim/hidden_dim/output_dim are aliased to
        # input_size/hidden_size/output_size.
        if self.input_size == 0 and self.input_dim != 0:
            self.input_size = self.input_dim   # alias: input_dim → input_size
        if self.hidden_size == 0 and self.hidden_dim != 0:
            self.hidden_size = self.hidden_dim
        if self.output_size == 0 and self.output_dim != 0:
            self.output_size = self.output_dim
        if self.random_seed is not None:
            np.random.seed(self.random_seed)
        # Xavier-like init: small random values to start training
        self.Wxh = np.random.randn(self.hidden_size, self.input_size) * 0.01
        self.Whh = np.random.randn(self.hidden_size, self.hidden_size) * 0.01
        self.Why = np.random.randn(self.output_size, self.hidden_size) * 0.01
        self.bh  = np.zeros((self.hidden_size, 1))
        self.by  = np.zeros((self.output_size, 1))

    def forward(self, x: np.ndarray, h: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
        # Standard RNN recurrence: h_t = tanh(W_xh·x_t + W_hh·h_{t-1} + b_h)
        # y_t = W_hy·h_t + b_y
        x = np.atleast_1d(x).flatten()
        h = np.atleast_1d(h).flatten()
        h = np.tanh(np.dot(self.Wxh, x) + np.dot(self.Whh, h) + self.bh.flatten())
        y = np.dot(self.Why, h) + self.by.flatten()
        return y, h

4.9 validation.py — Schema-Driven Validation

src/ai_core/validation.pyPython@dataclass
class DataSchema:
    feature_names: list[str]           # ordered column names
    feature_types: dict[str, str]      # {"col": "float"|"int"|"binary"}
    required_columns: list[str]        # columns that must be present
    min_rows: int                      # minimum sample count
    max_rows: int | None               # optional maximum sample count
    value_ranges: dict[str, tuple]     # {"col": (lo, hi)} — per-column bounds
    categorical_values: dict[str, list] # {"col": [allowed_values]}

    def __post_init__(self):
        # Default: all feature_names are required if required_columns not explicitly set.
        if not self.required_columns:
            self.required_columns = self.feature_names

class DataValidator:
    def validate(self, X: np.ndarray, y: np.ndarray | None = None) -> ValidationResult:
        result = ValidationResult(valid=True)

        # 1. Normalize shape: 1D → 2D
        if X.ndim == 1: X = X.reshape(-1, 1)
        n_samples, n_features = X.shape

        # 2. Row count bounds
        if n_samples < self.schema.min_rows:   result.errors.append(...)
        if self.schema.max_rows and n_samples > self.schema.max_rows: result.errors.append(...)

        # 3. Feature count
        if n_features != len(self.schema.feature_names): result.errors.append(...)

        # 4. NaN / Inf detection
        if np.isnan(X).any():  result.errors.append("Input data contains NaN values")
        if np.isinf(X).any(): result.errors.append("Input data contains infinite values")

        # 5. Per-feature: value ranges, categorical values, binary constraints
        # 6. Labels: length match, NaN check
        # 7. Compute descriptive statistics (mean, std) for reporting

        result.valid = len(result.errors) == 0
        return result
