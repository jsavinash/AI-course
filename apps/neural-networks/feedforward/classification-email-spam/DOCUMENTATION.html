✉classification-email-spam

Supervised MLP Classifier  ·  Email Spam vs. Ham  ·  MLOps Example

◈Overview & Monorepo Context

classification-email-spam is a Python package that classifies emails as spam or ham using a feedforward neural network (MLP) implemented from scratch with NumPy. It sits in the feedforward monorepo and complements the other three apps by demonstrating supervised binary classification.

Unlike anomaly detection, this app uses labelled data (spam / ham) during training. The MLP learns a non-linear decision boundary in feature space defined by email characteristics like keyword presence, link count, sender reputation, and message length.

∫The Mathematical Foundation

Task type: Supervised binary classification.
Architecture: Input (n_features) → Hidden (ReLU) → Output (Sigmoid, 1 neuron).

1. Forward Pass

z₁ = W₁ · x + b₁
a₁ = ReLU(z₁) = max(0, z₁)
z₂ = W₂ · a₁ + b₂
ŷ = σ(z₂) = 1 / (1 + e^{-z₂})

The sigmoid squashes the output to (0, 1), interpreted as P(spam | x). Numerical stability is enforced by clipping z₂ to [−500, 500] before exponentiation.

2. Loss — Binary Cross-Entropy

L_BCE = −(1/n) · Σᵢ [ yᵢ · log(ŷᵢ) + (1−yᵢ) · log(1−ŷᵢ) ]

BCE is the canonical loss for binary classification with sigmoid outputs. It penalises confident wrong predictions exponentially: predicting ŷ=0.99 when y=0 incurs a massive penalty via log(0.01).

3. Gradients

∂L/∂z₂ = (ŷ − y) / n
∂L/∂W₂ = a₁ᵀ · ∂L/∂z₂ + 2λW₂
∂L/∂W₁ = xᵀ · (∂L/∂z₂ · W₂ᵀ ⊙ σ′(z₁)) + 2λW₁

The derivative of sigmoid + BCE collapses beautifully: ∂L/∂z₂ = ŷ − y. This is why logistic regression and sigmoid-output networks are so efficient — no messy chain-rule through the sigmoid derivative remains.

4. L2 Regularisation

L_total = L_BCE + λ · (‖W₁‖² + ‖W₂‖²)

Weight decay λ = 0.001 prevents overfitting, especially important with a small hidden layer (default 16 neurons) on a 12-feature input.

5. Why an MLP over Logistic Regression?

A single logistic-regression unit learns a linear decision boundary. The hidden ReLU layer introduces non-linearity, enabling the model to learn conjunctions of features (e.g., "has_link AND high amount AND !sender_reputation"). The extra capacity is warranted because spam vs. ham is not linearly separable in keyword-feature space.

Design Constraints & Patterns

  • Schema validation: DataValidator(create_email_spam_schema()) checks feature ranges before training and at every API request.
  • Input validation at the edge: The /predict and /predict/bulk endpoints call _validator.validate(X) and return HTTP 422 if features are out of bounds.
  • Decision threshold: Fixed at 0.5 probability. proba >= 0.5 → is_spam = True. The threshold is not tuned on a validation set — a deliberate simplification for the example.
  • Early stopping: Same 1e-7 convergence criterion as the other apps.
  • Validation accuracy tracking: Every 50 epochs, validation accuracy is recorded, enabling dual-axis training charts (loss + accuracy).

🔬Detailed Code Walkthrough

model.py — SpamDetectionNN

Numerically Stable Sigmoid

def _sigmoid(z):
    z = np.clip(z, -500, 500)   # prevent exp overflow
    return 1 / (1 + np.exp(-z))

Without clipping, large positive z → exp(-z) ≈ 0 → 1/0 = inf. Large negative z → exp(-z) = inf → 1/inf = 0, which is fine but wastes computation. The clip is a defensive guard against NaN propagation.

Binary Cross-Entropy with Clipping

def _binary_cross_entropy(y_true, y_pred):
    eps = 1e-9
    y_pred = np.clip(y_pred, eps, 1 - eps)   # avoid log(0)
    return float(-np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred)))

log(0) = -inf would produce NaN loss. Clipping predictions to [eps, 1-eps] ensures the gradient remains finite even when the model is very confident.

Backpropagation — Collapsed Sigmoid Gradient

dz2 = (output.flatten() - y) / m   # dL/dz2 for sigmoid+BCE
dW2 = np.dot(a1.T, dz2.reshape(-1, 1)) + self.weight_decay * self.W2
db2 = float(np.sum(dz2))

da1 = np.dot(dz2.reshape(-1, 1), self.W2.T)
dz1 = da1 * _relu_derivative(z1)   # ReLU gate: 1 if z1>0 else 0

dW1 = np.dot(X_norm.T, dz1) + self.weight_decay * self.W1
db1 = np.sum(dz1, axis=0)

The collapse dz2 = (output - y) / m is specific to sigmoid + BCE. If the output activation were tanh with MSE, the derivative chain would be longer and more expensive.

Evaluation Metrics

def evaluate(self, X, y):
    return {
        "accuracy": self.accuracy(X, y),
        "precision": self.precision(X, y),
        "recall": self.recall(X, y),
        "f1": self.f1_score(X, y),
        "roc_auc": self.roc_auc(X, y),
    }

ROC AUC is computed via the Wilcoxon-Mann-Whitney ranking formula rather than by integrating the ROC curve — a O(n log n) sort-based approximation that is exact for discrete score distributions.

data.py — Feature Engineering

12 binary / continuous features are generated with deliberate statistical skew:

  • Spam emails have high num_exclamations (5-20), high num_links (3-15), low sender_reputation (0-0.3).
  • Ham emails have longer body email_length (20-100), high sender_reputation (0.7-1.0), fewer links.

This inductive bias ensures the synthetic data is linearly separable enough for the MLP to learn quickly, while still requiring the hidden layer to capture non-linear interactions.

train.py — Validation Gate

validator = DataValidator(create_email_spam_schema())
validation = validator.validate(X, y)
if not validation.valid:
    raise ValueError(f"Training data validation failed: {validation.errors}")

Training halts immediately if the data schema is violated. This prevents silent training on corrupted inputs — a common MLOps anti-pattern.

api.py — Input Validation

def _compute_prediction(features: list[float]) -> PredictResponse:
    X = np.array([features])
    validation = _validator.validate(X)
    if not validation.valid:
        raise HTTPException(status_code=422, detail=validation.errors)
    proba = float(_model.predict_proba(X)[0])
    is_spam = bool(proba >= 0.5)
    ...

The same validator that guards training data also guards the API. This ensures the model never sees inputs outside the distribution it was trained on, reducing the risk of garbage-in/garbage-out predictions.

▶Examples & Usage

CLI Training

uv run python -m classification_email_spam.train \
  --model-dir ./artifacts/models \
  --n-samples 1000 \
  --hidden-dim 16 \
  --n-iterations 1000 \
  --weight-decay 0.001 \
  --register-mlflow

Python — Train & Predict

import numpy as np
from classification_email_spam.data import generate_synthetic_data
from classification_email_spam.model import SpamDetectionNN

X, y = generate_synthetic_data(n_samples=1000, random_seed=42)
model = SpamDetectionNN(hidden_dim=16, learning_rate=0.01, n_iterations=1000)
model.fit(X, y)

email = np.array([[
    1, 1, 1, 1, 1,   # has_free, win, link, exclamation, meeting
    35, 1, 1,         # length, caps, money
    8, 12, 1, 0.1    # num_links, exclamations, urgent, sender_rep
]])
proba = model.predict_proba(email)[0]
print(f"spam probability: {proba:.4f}")  # Expected: high (near 1.0)
