🏠regression-house-price

Supervised MLP Regressor  ·  House Price Prediction  ·  MLOps Example

◈Overview & Monorepo Context

regression-house-price is a Python package that predicts house prices from property features using a feedforward neural network (MLP) implemented from scratch with NumPy. It lives in the feedforward monorepo and represents the supervised regression task type.

The app predicts a continuous target (price in USD) from 10 features including square footage, bedrooms, bathrooms, location score, property age, garage size, lot size, year built, property type, and school rating.

∫The Mathematical Foundation

Task type: Supervised regression (continuous target).
Architecture: Input (n_features) → Hidden (ReLU) → Output (Linear, 1 neuron).

1. Forward Pass

z₁ = W₁ · x + b₁
a₁ = ReLU(z₁)
ŷ = W₂ · a₁ + b₂  (linear output — no activation)

The output layer is intentionally linear because the target (price) is unbounded above. A sigmoid or tanh output would clip predictions, which is inappropriate for regression. The model learns to predict the normalised target; at inference time the prediction is denormalised back to USD.

2. Loss — Mean Squared Error

L_MSE = (1/n) · Σᵢ (yᵢ − ŷᵢ)²

MSE penalises large errors quadratically, which is appropriate when we want the model to avoid outlier predictions. The gradient is simply 2·(ŷ−y)/n, making backpropagation efficient.

3. Total Loss with L2 Regularisation

L_total = MSE(y, ŷ) + λ · (‖W₁‖² + ‖W₂‖²)

4. Gradient Descent Updates

∂L/∂ŷ = 2·(ŷ − y) / n
∂L/∂W₂ = a₁ᵀ · ∂L/∂ŷ + 2λW₂
∂L/∂W₁ = xᵀ · (∂L/∂ŷ · W₂ᵀ ⊙ ReLU′(z₁)) + 2λW₁
W ← W − α · ∂L/∂W

α (learning rate = 0.001) controls step size. Too large → divergence; too small → slow convergence. The default is chosen conservatively for stability on small datasets.

5. Target Normalisation

y_norm = (y − μ_y) / σ_y
ŷ = ŷ_norm · σ_y + μ_y

Features and targets are normalised to zero mean and unit variance before training. This ensures the loss landscape is well-conditioned and both weights and biases converge at similar rates. At prediction time, the output is denormalised to return a USD price.

6. Why a Neural Network over Linear Regression?

A single linear layer (y = wx + b) can only learn linear relationships. House prices have non-linear interactions: the value of a bedroom depends on total square footage, location premium interacts with property type, and age has a non-linear depreciation curve. A hidden ReLU layer with 32 neurons captures these interactions.

Design Constraints & Patterns

  • Target normalisation: Both X and y are standardised. The model stores y_mean_ and y_std_ for denormalisation at prediction time.
  • Dual normalisation guard: std_ for features and y_std_ for targets are clamped to a minimum of 1e-8 to avoid division by zero on constant columns.
  • Validation loss tracking: Unlike classification (which tracks accuracy), regression tracks MSE on the validation set every 50 epochs.
  • Early stopping: Same 1e-7 convergence criterion.
  • Model registry fallback chain: Identical to the other apps — registry, direct NPZ, bundled, baseline.

🔬Detailed Code Walkthrough

model.py — HousePriceNN

Target Normalisation in fit()

self.y_mean_ = float(y.mean())
self.y_std_ = float(y.std()) if y.std() > 1e-8 else 1.0
y_norm = (y - self.y_mean_) / self.y_std_

Target normalisation is critical for regression. Prices span tens or hundreds of thousands; without normalisation, the initial random weights produce outputs in the wrong order of magnitude, causing gradient explosion or vanishing. Standardising y to unit variance puts it on the same scale as the hidden activations.

Prediction Denormalisation

def predict(self, X):
    X_norm = (X - self.mean_) / self.std_
    output, _, _ = self._forward(X_norm)
    return output * self.y_std_ + self.y_mean_

The model's raw output is output (shape: n_samples,), which is the normalised prediction. Multiplying by y_std_ and adding y_mean_ rescales it back to USD. This two-step normalisation/denormalisation is invisible to API consumers, who always receive real dollar amounts.

Backpropagation

dz2 = 2 * (output - y_norm) / m     # dL/dz2 for MSE
dW2 = np.dot(a1.T, dz2.reshape(-1, 1)) + self.weight_decay * self.W2
db2 = np.sum(dz2)

da1 = np.dot(dz2.reshape(-1, 1), self.W2.T)
dz1 = da1 * _relu_derivative(z1)

dW1 = np.dot(X_norm.T, dz1) + self.weight_decay * self.W1
db1 = np.sum(dz1, axis=0)

The MSE gradient dz2 = 2·(output − y)/m is the only difference from the classification backprop (where dz2 = (probs − y_onehot)/m). This highlights how changing the output activation and loss function changes only the first step of the gradient chain.

Evaluation Metrics

def evaluate(self, X, y):
    return {
        "mse": self.mse(X, y),
        "rmse": self.rmse(X, y),
        "mae": self.mae(X, y),
        "r2": self.r2_score(X, y),
    }

R² (coefficient of determination) measures the fraction of variance explained. R² = 1.0 means perfect predictions; R² = 0.0 means the model is no better than predicting the mean. It is computed as 1 − SS_res / SS_tot.

data.py — Synthetic Price Formula

price = (
    50000
    + sqft * rng.uniform(80, 150, n_samples)
    + bedrooms * 15000
    + bathrooms * 20000
    + location_score * 1500
    - age * 1500
    + garage * 8000
    + lot_size * 2
    + school_rating * 25000
    + property_type * 30000
    + rng.normal(0, 20000, n_samples)   # noise
)

The price is a linear combination of features plus Gaussian noise (σ = $20,000). The noise ensures the model cannot achieve R² = 1.0, mimicking real-world irreducible error. Location score is derived from a discrete mapping (downtown=85, beach=90, rural=55), introducing a non-linear step function the MLP must approximate.

api.py — Schema Validation

_validator = DataValidator(create_house_price_schema())

validation = _validator.validate(X)

    raise HTTPException(status_code=422, detail=validation.errors)

Input validation rejects out-of-range feature values (e.g., negative square footage, bedrooms > 20) before they reach the model. This prevents nonsensical predictions and provides clear error messages to API consumers.

▶Examples & Usage

CLI Training

uv run python -m regression_house_price.train \
  --model-dir ./artifacts/models \
  --n-samples 1000 \
  --hidden-dim 32 \
  --n-iterations 2000 \
  --weight-decay 0.0001 \
  --register-mlflow

Python — Train & Predict

import numpy as np
from regression_house_price.data import generate_synthetic_data
from regression_house_price.model import HousePriceNN

X, y = generate_synthetic_data(n_samples=1000, random_seed=42)
model = HousePriceNN(hidden_dim=32, learning_rate=0.001, n_iterations=2000)
model.fit(X, y)

house = np.array([[
    2500.0,  # sqft
    4.0,     # bedrooms
    3.0,     # bathrooms
    85.0,    # location_score (downtown)
    10.0,    # age
    2.0,     # garage
    8000.0,  # lot_size
    2014.0,  # year_built
    0.0,     # property_type (single-family)
    8.5,     # school_rating
]])
price = model.predict(house)[0]
print(f"Predicted price: ${price:,.2f}")
