📋 Overview & Monorepo Context

Name, purpose, role, and dependencies within the broader monorepo.

Package Identity

  • Package name: medical-imaging
  • Module: cnn_medical_imaging
  • Version: 0.1.0
  • Description: Detects tumors or fractures in synthetic medical X-ray, MRI, and CT scan images using a CNN.

Monorepo Role

This app is one of nine CNN-family MLOps reference implementations under apps/neural-networks/convolutional/. It demonstrates a complete supervised-classification pipeline — from synthetic 8×8 grayscale image generation through training, model-registry persistence, and a productionised FastAPI serving layer with Prometheus metrics and drift detection.

Key Dependencies

  • ai-core — shared workspace library (logging, model registry, drift detection, validation schemas, metrics)
  • numpy >= 1.26.0 — all numerical computation
  • fastapi + uvicorn — HTTP serving
  • pydantic >= 2.6.0 — request/response models
  • prometheus-client — metrics exposition
  • matplotlib — training-loss charting

Output Contract

  • Task type: Multi-class classification (3 classes: normal, benign, malignant)
  • Input shape: (N, 1, 8, 8) — 8×8 grayscale pixel arrays, flattened to 64 features
  • Output: Class probability vector via softmax; argmax gives predicted condition label
  • Loss: Categorical cross-entropy
  • Framework: Pure NumPy (no PyTorch / TensorFlow)

∫ The Mathematical Foundation

Rigorous breakdown of the CNN forward-pass equations, loss, and optimisation used in this app.

▸ Core Equations

E1 $$Z^{(l)} = W^{(l)} * X^{(l)} + b^{(l)}$$
2-D convolution: valid padding, stride 1. W = (Cout, Cin, k, k), X = (N, Cin, H, W).
E2 $$A^{(l)} = \text{ReLU}\!\left(Z^{(l)}\right) = \max(0, Z^{(l)})$$
Element-wise non-linearity. Introduces the piecewise-linear non-linearity necessary for universal approximation.
E3 $$\text{MaxPool}_{2\times2}(X)_{i,j} = \max_{m\in\{2i,2i+1\},\;n\in\{2j,2j+1\}} X_{m,n}$$
Halves H and W, providing translation invariance and reducing parameter count in subsequent layers.
E4 $$\text{Softmax}(z)_j = \frac{e^{z_j}}{\sum_{k=1}^{K} e^{z_k}}, \quad K=3$$
Converts the final dense-layer logits into a valid categorical probability distribution.
E5 $$\mathcal{L}_{CE} = -\sum_{i=1}^{C} y_i \log(\hat{y}_i)$$
Categorical cross-entropy. y is the one-hot ground-truth vector; ŷy is the softmax output. Minimising this maximises the log-likelihood of the correct class.
E6 $$\theta \leftarrow \theta - \alpha\,\nabla_\theta\mathcal{L} - \alpha\lambda\theta$$
Gradient-descent update with L2 weight decay (λ = 0.001). The weight-decay term λθ penalises large weights, reducing overfitting on small 8×8 synthetic inputs.

▸ Why This Architecture?

Conv2D + ReLU

Local connectivity drastically reduces parameters vs. a fully-connected first layer, while weight sharing enables translation-equivariant feature detection across the 8×8 spatial grid.

MaxPool 2×2

Reduces spatial dimensions from 6×6 to 3×3 after two conv layers, providing mild translational invariance and cutting computation in the dense layer by ~75 %.

He Initialisation

Weights drawn from N(0, √(2/fan_in)) preserve variance through ReLU layers, preventing vanishing gradients in the early epochs of this small dataset.

Gradient Clipping (clip=5.0)

Norms are capped at 5.0 before each parameter update, stabilising training on synthetic data where high-frequency noise can produce sharp loss spikes.

Step-by-Step Derivation: Forward Pass

  1. Input X of shape (N, 1, 8, 8) is convolved with 8 filters of size 3×3: output spatial size = 8 − 3 + 1 = 6. Shape: (N, 8, 6, 6).
  2. ReLU is applied element-wise: negative pre-activations become zero, introducing non-linearity.
  3. MaxPool 2×2 halves H and W: (N, 8, 3, 3).
  4. Flatten to (N, 72).
  5. Dense layer to 32 units + ReLU.
  6. Dense layer to 3 units + Softmax.
  7. Cross-entropy loss is computed against the one-hot label vector.

📝 Detailed Code Walkthrough

Deep dive into the key files, classes, and functions — annotated with rationale.

model.py — MedicalImagingCNN dataclass (lines 19–152)

The public-facing model class is a thin @dataclass wrapper around ai_core.nn_utils.cnn.SimpleCNN. It exists to (a) provide a domain-specific name and docstrings, (b) inject task-specific defaults (IMG_SIZE=8, N_CHANNELS=1, output_dim=3), and (c) expose a uniform interface (fit / predict / evaluate / save / load) that mirrors the other CNN family apps.

@dataclass
class MedicalImagingCNN:
    IMG_SIZE: int = 8          # Square input dimension
    N_CHANNELS: int = 1       # Grayscale — single channel
    n_filters: int = 8        # Conv2D output channels
    kernel_size: int = 3    # 3×3 receptive field
    hidden_dim: int = 32    # Dense hidden layer width
    output_dim: int = 3     # 3 diagnostic classes
    learning_rate: float = 0.05
    n_iterations: int = 300
    weight_decay: float = 0.001
    clip_value: float = 5.0   # Max gradient norm
    random_seed: int = 42
    model: SimpleCNN | None = None   # Populated after fit()
    loss_history: list[float] = field(default_factory=list)

model.py — fit() (lines 53–94)

fit() reshapes the flat (N, 64) input to (N, 1, 8, 8), one-hot encodes labels, constructs the SimpleCNN with output_activation="softmax" and output_loss="cross_entropy", then delegates training to SimpleCNN.fit(). It stores the resulting loss_history for charting and metric reporting.

def fit(self, X, y, X_val=None, y_val=None) -> "MedicalImagingCNN":
    X_img = reshape_image(X)                    # (N,64) → (N,1,8,8)
    y_arr = np.asarray(y, dtype=float)
    # One-hot encode for 3-class cross-entropy
    onehot = np.zeros((len(y_arr), self.output_dim))
    onehot[np.arange(len(y_arr)), y_arr.astype(int)] = 1.0
    y_arr = onehot

    self.model = SimpleCNN(
        input_shape=(self.N_CHANNELS, self.IMG_SIZE, self.IMG_SIZE),
        n_filters=self.n_filters,
        kernel_size=self.kernel_size,
        hidden_dim=self.hidden_dim,
        output_dim=self.output_dim,
        output_activation="softmax",
        output_loss="cross_entropy",
        learning_rate=self.learning_rate,
        weight_decay=self.weight_decay,
        clip_value=self.clip_value,
        random_seed=self.random_seed,
    )
    self.model.fit(X_img, y_arr, n_iterations=self.n_iterations)
    self.loss_history = self.model.loss_history
    return self

data.py — Synthetic Data Generation (lines 1–103)

generate_synthetic_data() creates N_CLASSES=3 distinct spatial templates (centre-square, upper-half, diagonal-stripe) on an 8×8 grid. Gaussian noise (σ = 0.2) is added and the result is clipped to [0, 1]. The _create_template() function indexes into a list of 10 lambda pattern functions; only the first 3 are used (for the 3 classes). train_test_split() uses np.random.default_rng for permutation, ensuring reproducibility when a seed is provided.

# Three distinct spatial patterns for the 3 diagnostic classes:
patterns = [
    lambda r, c: IMAGE_SIZE//4 <= r <= 3*IMAGE_SIZE//4 # centre square → 'normal'
               and IMAGE_SIZE//4 <= c <= 3*IMAGE_SIZE//4,
    lambda r, c: r < IMAGE_SIZE//2                   # upper half → 'benign'
    lambda r, c: (r + c) % 3 == 0             # diagonal stripes → 'malignant'
]
LABEL_NAMES = ['normal', 'benign', 'malignant']

train.py — Orchestration Pipeline (lines 21–208)

The train() function is the single entry-point for CI/CD and local runs. It chains: data loading → validation → train/test split → model construction → training → evaluation → model persistence → registry → (optional) MLflow logging. All hyperparameters are exposed as CLI arguments via argparse with environment-variable defaults, enabling containerised overrides without code changes.

api.py — FastAPI Serving Layer (lines 1–324)

The serving layer uses a @asynccontextmanager lifespan to initialise all shared state (model, metrics collector, validator, drift detector) once at startup. The module-level _model singleton avoids repeated deserialisation. Key endpoints:

  • POST /predict — single-sample inference with input validation and metrics recording
  • POST /predict/bulk — batch inference (1–50 samples), loop over _compute_prediction()
  • GET /stats — model metadata, epoch count, final loss
  • GET /drift — PSI-based drift detection against reference data (requires ≥10 predictions)
  • POST /reload — hot-swap model version without container restart
  • GET /metrics — Prometheus generate_latest() exposition

▶️ Examples & Usage

Practical code examples for initialising, training, and serving the model.

Train via CLI

uv run python -m cnn_medical_imaging.train \
  --model-dir ./artifacts/models \
  --n-samples 1000 \
  --n-filters 16 \
  --n-iterations 500 \
  --learning-rate 0.03 \
  --register-mlflow

Train Programmatically

from pathlib import Path
from cnn_medical_imaging.model import MedicalImagingCNN
from cnn_medical_imaging.data import generate_synthetic_data, train_test_split

X, y = generate_synthetic_data(n_samples=500, random_seed=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_seed=42)

model = MedicalImagingCNN(
    n_filters=16, kernel_size=3,
    hidden_dim=64, learning_rate=0.03,
    n_iterations=500, weight_decay=0.001,
)
model.fit(X_train, y_train, X_val=X_test, y_val=y_test)
metrics = model.evaluate(X_test, y_test)
print(f"Test accuracy: {metrics['accuracy']:.2%}")
model.save("./artifacts/medical_imaging_v2.npz")

Predict Single Sample

import numpy as np
from cnn_medical_imaging.model import MedicalImagingCNN

model = MedicalImagingCNN.load("./artifacts/medical_imaging_v2.npz")

# 64-pixel flat vector representing an 8x8 grayscale image
sample = np.random.rand(64).astype(np.float32)
probas = model.predict_proba(sample.reshape(1, -1))
pred_class = int(np.argmax(probas))
print(f"Predicted: {['normal','benign','malignant'][pred_class]}")
print(f"Confidence: {probas[0][pred_class]:.4f}")
