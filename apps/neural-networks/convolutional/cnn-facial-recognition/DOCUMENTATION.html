📋 Overview & Monorepo Context

Name, purpose, role, and dependencies within the broader monorepo.

Package Identity

  • Package name: facial-recognition
  • Module: cnn_facial_recognition
  • Version: 0.1.0
  • Description: Binary facial recognition for phone unlock and photo tagging using a CNN.

Monorepo Role

One of three CNN-family MLOps reference implementations under apps/neural-networks/convolutional/. Demonstrates binary classification with a sigmoid output — distinguishing it from the 3-class medical-imaging and video-surveillance apps. Shares the identical pipeline structure (synthetic data → SimpleCNN → ModelRegistry → FastAPI), differing only in output activation, loss type, and label schema.

Key Dependencies

  • ai-core — shared workspace (logging, registry, drift, validation, metrics)
  • numpy >= 1.26.0 — all numerical computation
  • fastapi + uvicorn — HTTP serving
  • pydantic >= 2.6.0 — request/response validation
  • prometheus-client — metrics exposition
  • matplotlib — training-loss charting

Output Contract

  • Task type: Binary classification (owner vs. not_owner)
  • Input shape: (N, 1, 8, 8) — 8×8 grayscale pixel arrays, flattened to 64 features
  • Output: Sigmoid scalar probability; threshold 0.5 → boolean is_owner
  • Loss: Binary cross-entropy
  • Framework: Pure NumPy (no PyTorch / TensorFlow)

∫ The Mathematical Foundation

CNN forward-pass equations; sigmoid binary cross-entropy; gradient descent with L2.

▸ Core Equations

E1 $$Z^{(l)} = W^{(l)} * X^{(l)} + b^{(l)}$$
2-D convolution, valid padding, stride 1.
E2 $$A^{(l)} = \text{ReLU}\!\left(Z^{(l)}\right) = \max(0, Z^{(l)})$$
E3 $$\text{MaxPool}_{2\times2}(X)_{i,j} = \max_{m\in\{2i,2i+1\},\;n\in\{2j,2j+1\}} X_{m,n}$$
E4 $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
Sigmoid activation on the final dense unit, squashing logits to [0, 1].
E5 $$\mathcal{L}_{BCE} = -\frac{1}{N}\sum_{i=1}^{N}\!\Big[y_i\log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)\Big]$$
Binary cross-entropy loss. The derivative w.r.t. pre-sigmoid logit simplifies to ŷy − y, which the SimpleCNN backward pass uses directly.
E6 $$\theta \leftarrow \theta - \alpha\,\nabla_\theta\mathcal{L} - \alpha\lambda\theta$$
Gradient descent with L2 weight decay (λ = 0.001). Gradient norm is clipped at 5.0.

▸ Why Sigmoid + BCE Instead of Softmax + CE?

Mutually Exclusive Binary Output

Sigmoid + BCE models P(y=1|x) directly, calibrated as a probability. For phone-unlock / photo-tagging, a calibrated confidence score is operationally meaningful (threshold can be tuned for FAR/FRR trade-offs).

Gradient Stability

BCE gradient ŷy − y is simpler and numerically more stable than the softmax cross-entropy gradient for a 2-class problem, reducing the risk of saturation in the small 8×8 input regime.

Architecture Parity

The only structural difference from the 3-class apps is output_dim=1, output_activation="sigmoid", and output_loss="binary_crossentropy". All other layers, hyperparameters, and the pipeline are identical, keeping the monorepo's pedagogical consistency.

Output Interpretation

The API returns is_owner: bool derived from proba >= 0.5. Confidence is max(proba, 1-proba), so it is always ≥ 0.5 and represents certainty regardless of which side of the threshold the raw sigmoid falls.

Step-by-Step: Binary Prediction Path

  1. Input (N, 1, 8, 8) → Conv2D(8, 3×3) → (N, 8, 6, 6)
  2. ReLU → MaxPool 2×2 → (N, 8, 3, 3) → Flatten (N, 72)
  3. Dense(32) + ReLU → Dense(1) + Sigmoid → scalar ŷy ∈ [0,1]
  4. BCE loss: ℓ = −[y log(ŷy) + (1−y) log(1−ŷy)]
  5. Backprop: ∂ℓ/∂z = ŷy − y (streamlined sigmoid-CE derivative)
  6. Gradient clipped at ||g||&sub2; ≤ 5.0, then SGD update with L2 decay.

model.py — fit() (lines 53–94)

When output_dim == 1, labels are reshaped to (N, 1) (no one-hot encoding). The SimpleCNN is instantiated with output_activation="sigmoid" and output_loss="binary_crossentropy".

api.py — Binary Prediction Logic (lines 266–302)

The _compute_prediction() function extracts the sigmoid probability and applies the 0.5 threshold. Confidence is symmetrised with max(proba, 1-proba) so the API always returns a value ≥ 0.5 regardless of which class was predicted.

def _compute_prediction(is_owner: list[float]):
    probas = _model.predict_proba(X)[0]       # shape (1,) — single sigmoid
    proba = float(probas[0])              # raw sigmoid output
    is_owner = bool(proba >= 0.5)          # threshold decision
    confidence = round(float(max(proba, 1 - proba)), 4)
    # confidence ∈ [0.5, 1.0] — always ≥ threshold
    response = PredictResponse(
        is_owner=is_owner,
        confidence=confidence,
        model_version=_model_version,
        training_mode=_model.training_mode,
    )

api.py — Drift Detection Configuration (lines 76–104)

The lifespan() async context manager is the app initialisation hook. It creates a DriftDetector with 64 pixel features and a PSI threshold of 0.2. The _recent_predictions list stores raw input vectors (not predictions) for drift monitoring — up to 1000 entries, with the oldest dropped when the limit is exceeded.

Train Programmatically

from pathlib import Path
from cnn_facial_recognition.model import FacialRecognitionCNN
from cnn_facial_recognition.data import generate_synthetic_data, train_test_split

X, y = generate_synthetic_data(n_samples=500, random_seed=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_seed=42)

model = FacialRecognitionCNN(
    n_filters=16, kernel_size=3,
    hidden_dim=64, learning_rate=0.03,
    n_iterations=500, weight_decay=0.001,
)
model.fit(X_train, y_train, X_val=X_test, y_val=y_test)
metrics = model.evaluate(X_test, y_test)
print(f"Test accuracy: {metrics['accuracy']:.2%}")
model.save("./artifacts/facial_recognition_v2.npz")

Predict — Single Face Image

import numpy as np
from cnn_facial_recognition.model import FacialRecognitionCNN

model = FacialRecognitionCNN.load("./artifacts/facial_recognition_v2.npz")

sample = np.random.rand(64).astype(np.float32)
proba = model.predict_proba(sample.reshape(1, -1))[0][0]
is_owner = proba >= 0.5
confidence = max(proba, 1 - proba)
print(f"is_owner={is_owner}, confidence={confidence:.4f}")
# Output: is_owner=True, confidence=0.8721
