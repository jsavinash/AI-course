1. Overview & Monorepo Context

Name, purpose, and role within the broader monorepo.

Package name: self-supervised-monitoring
Version: 0.1.0
Purpose: Detect anomalies in server metrics using a denoising autoencoder trained in a self-supervised manner. The model learns to reconstruct normal server metrics from corrupted inputs; at inference time, high reconstruction error signals an anomaly. No human labels are required for training.

Monorepo role: Lives under self-supervised/. It depends on ai-core for shared infrastructure. The app is architecturally similar to anomaly-detection-pca but uses a neural autoencoder instead of linear PCA, enabling nonlinear reconstruction.

2. The Mathematical Foundation

Denoising autoencoder, MSE reconstruction, and anomaly thresholding.

$$\hat{x} = g_\theta(f_\theta(\tilde{x}))$$
$$\mathcal{L}_{recon} = \frac{1}{n} \sum_{i=1}^{n} \|x_i - \hat{x}_i\|^2$$
$$a^{(1)} = \text{ReLU}(W^{(1)} x + b^{(1)})$$
$$\hat{x} = W^{(2)} a^{(1)} + b^{(2)}$$
$$\text{anomaly} = \text{MSE}(x, \hat{x}) > \tau$$

Why this math? The denoising autoencoder corrupts inputs (zeroing out features + Gaussian noise) and learns to reconstruct the original clean input. The encoder f_θ compresses to a hidden bottleneck, forcing the model to learn robust features. The decoder g_θ reconstructs. MSE is the reconstruction loss. At inference, anomalies are detected by thresholding the per-sample reconstruction error; anomalies were never seen during training, so the model cannot reconstruct them well. He initialization is used for ReLU layers to maintain gradient variance.

3. Core Logic & Architecture

Data flow, design patterns, and lifecycle.

graph TD
  A[Synthetic Normal Metrics] --> B[Corrupt inputs: dropout + noise]
  B --> C[DenoisingAutoencoder.fit]
  C --> D[Forward: encode -> decode]
  D --> E[Backprop: MSE loss]
  E --> F[Compute threshold from train errors]
  F --> G[ModelRegistry.save]
  G --> H[FastAPI lifespan load]
  H --> I[/predict /predict/bulk /stats /model/info]

Design patterns:

  • Self-supervised task: The label is the original uncorrupted input. No human annotation is needed.
  • Two-layer network: Input → hidden (ReLU) → output (linear). The bottleneck forces dimensionality reduction.
  • Corruption strategy: Random feature dropout (zeroing) plus Gaussian noise, creating a robust denoising objective.
  • Threshold from training data: The anomaly threshold is set at the 95th percentile of training reconstruction errors, ensuring normal data rarely triggers alerts.

Primary execution path: train.py:main() → generates synthetic normal data → splits train/val/test → fits DenoisingAutoencoder → evaluates accuracy on test set → saves artifacts → registers model.

Key files, classes, and functions.

model.py — DenoisingAutoencoder

def _forward(self, X: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]:
    """Forward pass: encode -> decode."""
    z1 = np.dot(X, self.W1) + self.b1
    if self.hidden_activation == "relu":
        a1 = _relu(z1)
        da1 = _relu_derivative(z1)
    else:
        a1 = np.tanh(z1)
        da1 = 1 - np.tanh(z1) ** 2
    z2 = np.dot(a1, self.W2) + self.b2
    return z2, a1, z1, da1

def fit(self, X, X_val=None, X_test=None, y_test=None) -> "DenoisingAutoencoder":
    rng = np.random.default_rng(self.random_seed)
    self.input_dim = X.shape[1]
    self.W1 = self._he_init(X.shape[1], self.hidden_dim, rng)
    self.b1 = np.zeros(self.hidden_dim)
    self.W2 = self._xavier_init(self.hidden_dim, X.shape[1], rng)
    self.b2 = np.zeros(X.shape[1])

    self.mean_ = X.mean(axis=0)
    self.std_ = np.where(X.std(axis=0) < 1e-8, 1.0, X.std(axis=0))
    X_norm = (X - self.mean_) / self.std_

    for epoch in range(self.n_iterations):
        X_noisy = self._corrupt(X_norm, rng)
        z2, a1, z1, da1 = self._forward(X_noisy)
        loss = _mse_loss(X_norm, z2)
        self.loss_history.append(loss)

        # Backpropagation
        m = len(X_norm)
        dz2 = 2 * (z2 - X_norm) / m
        dW2 = np.dot(a1.T, dz2)
        db2 = np.sum(dz2, axis=0)
        da1 = np.dot(dz2, self.W2.T)
        dz1 = da1 * da1
        dW1 = np.dot(X_noisy.T, dz1)
        db1 = np.sum(dz1, axis=0)

        self.W1 -= self.learning_rate * dW1
        self.b1 -= self.learning_rate * db1
        self.W2 -= self.learning_rate * dW2
        self.b2 -= self.learning_rate * db2

Why this design:

  • He initialization (sqrt(2/n_in)) is used for W1 with ReLU to preserve gradient variance. Xavier initialization (sqrt(1/n_in)) is used for W2 (linear output).
  • _corrupt() applies both dropout (random zeroing) and Gaussian noise, creating a diverse set of corrupted inputs for robust training.
  • Standardization (mean_, std_) is fitted on training data and reused at inference to avoid data leakage.
  • Early stopping triggers when loss change over 100 epochs falls below 1e-7.

5. Examples & Usage

Training, serving, and consuming the API.

CLI Training

uv run python -m self_supervised_monitoring.train --model-dir ./artifacts/models --hidden-dim 16 --n-iterations 5000 --noise-rate 0.25

Python Usage

from self_supervised_monitoring.model import DenoisingAutoencoder
import numpy as np

X_normal = np.random.randn(500, 10)
model = DenoisingAutoencoder(hidden_dim=16, learning_rate=0.01, n_iterations=5000, noise_rate=0.25)
model.fit(X_normal)

X_test = np.random.randn(10, 10)
errors = model.reconstruction_error(X_test)
anomalies = model.is_anomaly(X_test)
print(f"Anomalies: {int(np.sum(anomalies))}, Threshold: {model.threshold:.4f}")
