2. The Mathematical Foundation

Linear regression, MSE loss, and gradient descent.

$$\hat{y} = w \cdot x + b$$
$$\mathcal{L}_{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
$$\frac{\partial \mathcal{L}}{\partial w} = -\frac{2}{n} \sum_{i=1}^{n} x_i(y_i - \hat{y}_i)$$
$$\frac{\partial \mathcal{L}}{\partial b} = -\frac{2}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)$$
$$w \leftarrow w - \alpha \cdot \frac{\partial \mathcal{L}}{\partial w}, \quad b \leftarrow b - \alpha \cdot \frac{\partial \mathcal{L}}{\partial b}$$

Why this math? Linear regression is the simplest parametric model that yields a closed-form relationship between pizza diameter and price. Gradient descent on MSE is computationally cheap, easy to inspect, and sufficient for this small dataset. The learning rate α controls step size; too large causes divergence, too small causes slow convergence. The implementation uses vectorized NumPy operations for efficiency.

3. Core Logic & Architecture

Data flow, design patterns, and lifecycle.

graph TD
  A[Input CSV / Built-in Data] --> B[DataValidator]
  B --> C[Train/Test Split]
  C --> D[LinearRegression.fit]
  D --> E[ModelRegistry.save_model]
  E --> F[FastAPI Lifespan Load]
  F --> G[/predict /predict/bulk]
  G --> H[DriftDetector]
  H --> I[MetricsCollector Prometheus]

Design patterns:

  • Dataclass model: LinearRegression is a @dataclass with mutable training state (weight, bias, loss_history).
  • Resilient model loading: The API tries four fallback sources: model registry → direct NPZ → bundled artifacts → in-memory baseline. This ensures the service never crashes on cold start.
  • Lifespan-managed state: FastAPI lifespan loads the model once at startup and exposes it via module-level globals.
  • Drift tracking: Recent predictions are stored in a bounded deque (max 1000) and compared against reference training data using PSI.

Primary execution path (training): train.py:main() parses CLI args → loads data → validates → splits → fits model → evaluates → saves artifacts → registers model → optionally logs to MLflow.

4. Detailed Code Walkthrough

Key files, classes, and functions.

model.py — LinearRegression

The core model is a single dataclass (~111 lines). It implements gradient descent from scratch.

@dataclass
class LinearRegression:
    learning_rate: float = 0.001
    n_iterations: int = 2000
    weight: float = 0.0
    bias: float = 0.0
    loss_history: list[float] = field(default_factory=list)

    def predict(self, X: np.ndarray) -> np.ndarray:
        """Forward pass: y_hat = w * x + b."""
        return self.weight * X + self.bias

    def fit(self, X: np.ndarray, y: np.ndarray) -> "LinearRegression":
        """Train using gradient descent on Mean Squared Error."""
        n = len(X)
        self.loss_history = []
        for _ in range(self.n_iterations):
            y_pred = self.predict(X)
            loss = np.mean((y_pred - y) ** 2)
            self.loss_history.append(float(loss))

            # MSE gradients
            dw = (2 / n) * np.sum(X * (y_pred - y))
            db = (2 / n) * np.sum(y_pred - y)

            self.weight -= self.learning_rate * dw
            self.bias -= self.learning_rate * db
        return self

Why this design:

  • The gradient formulas are derived analytically from ∂L/∂w and ∂L/∂b. Using vectorized NumPy avoids Python loops over samples.
  • loss_history is recorded every iteration for visualization and convergence debugging.
  • Serialization uses np.savez to store parameters plus metadata (learning rate, iterations) in a single archive.

api.py — Model Loading & Prediction

The API uses a four-tier fallback strategy to avoid cold-start failures:

def _load_model() -> tuple[LinearRegression, str]:
    # 1. Try model registry
    registry = ModelRegistry(base_dir=MODEL_DIR)
    try:
        if MODEL_VERSION == "latest":
            models = registry.list_models()
            pizza_models = [m for m in models if m.get("model_name") == "pizza-price"]
            if pizza_models:
                pizza_models.sort(key=lambda m: m["model_version"], reverse=True)
                latest = pizza_models[0]
                model_dir = Path(latest["artifact_path"])
                npz_files = list(model_dir.glob("pizza_model_*.npz"))
                if npz_files:
                    return LinearRegression.load(str(npz_files[0])), latest["model_version"]
    except Exception as e:
        logger.warning(f"Registry lookup failed: {e}")

    # 2. Try direct model in MODEL_DIR
    npz_path = MODEL_DIR / "pizza_model.npz"
    if npz_path.exists():
        return LinearRegression.load(str(npz_path)), "legacy"

    # 3. Try bundled artifacts directory
    candidate_paths = [
        Path("/app/artifacts/models/pizza_model_v1.0.0.npz"),
        Path(__file__).resolve().parents[3] / "artifacts" / "models" / "pizza_model_v1.0.0.npz",
    ]
    for p in candidate_paths:
        if p.exists():
            return LinearRegression.load(str(p)), "1.0.0-bundled"

    # 4. In-memory baseline fallback (never crash cold start)
    X_base, y_base = load_training_data(None)
    model = LinearRegression(learning_rate=0.001, n_iterations=2000)
    model.fit(X_base, y_base)
    return model, "1.0.0-baseline"

5. Examples & Usage

Training, serving, and consuming the API.

CLI Training

uv run python -m pizza_price.train --model-dir ./artifacts/models --learning-rate 0.001 --n-iterations 2000

Python API Usage

from pizza_price.model import LinearRegression
import numpy as np

# Initialize and train
model = LinearRegression(learning_rate=0.001, n_iterations=2000)
X = np.array([6, 8, 10, 14, 18], dtype=float)
y = np.array([7.0, 9.0, 13.0, 17.5, 18.0], dtype=float)
model.fit(X, y)

# Predict
price = model.predict(np.array([12.0]))[0]
print(f"Predicted price for 12-inch pizza: ${price:.2f}")
print(f"Equation: price = {model.weight:.4f} * diameter + {model.bias:.4f}")

REST API Requests

# Single prediction
curl -X POST http://localhost:8001/predict \

# Bulk prediction
curl -X POST http://localhost:8001/predict/bulk \
