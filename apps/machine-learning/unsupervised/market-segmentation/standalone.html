2. The Mathematical Foundation

K-Means objective, Lloyd's algorithm, and silhouette score.

$$\min_S \sum_{i=1}^{k} \sum_{x \in S_i} \|x - \mu_i\|^2$$
$$\mu_i = \frac{1}{|S_i|} \sum_{x \in S_i} x$$
$$J = \sum_{i=1}^{n} \|x^{(i)} - \mu_{c^{(i)}}\|^2$$
$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

Why this math? K-Means minimizes within-cluster sum of squares (inertia). Lloyd's algorithm alternates between assignment (E-step) and centroid update (M-step), guaranteeing convergence to a local optimum. Multiple initializations (n_init=10) are used to escape poor local minima. The silhouette score measures cluster separation: a(i) is mean intra-cluster distance, b(i) is mean nearest-cluster distance. Feature standardization ensures Euclidean distance is not dominated by scale.

3. Core Logic & Architecture

Data flow, design patterns, and lifecycle.

graph TD
  A[Synthetic / CSV Customer Data] --> B[Standardize features]
  B --> C[KMeans.fit: n_init random initializations]
  C --> D[Pick best run by lowest inertia]
  D --> E[Compute cluster profiles]
  E --> F[ModelRegistry.save]
  F --> G[FastAPI lifespan load]
  G --> H[/segment /segment/bulk /profiles]

Design patterns:

  • Multiple initializations: _fit_once() runs a single K-Means iteration; fit() repeats it n_init times and keeps the best result by inertia.
  • Confidence scoring: predict_confidence() computes 1 - (nearest / second_nearest), giving a [0,1] confidence based on relative distance to competing centroids.
  • Cluster profiles: cluster_profiles() returns per-cluster statistics (mean income, mean spending, member count, percentage) for business dashboards.
  • Human-readable names: SEGMENT_NAMES maps cluster indices to business-friendly labels.

Primary execution path: train.py:main() → loads customer data → validates → fits KMeans → evaluates inertia and silhouette → saves chart with centroids → registers model.

4. Detailed Code Walkthrough

Key files, classes, and functions.

model.py — KMeans

def _fit_once(self, X: np.ndarray, rng: np.random.Generator) -> tuple[np.ndarray, np.ndarray, float, int]:
    """Run K-Means once with a single random initialization."""
    n_samples, n_features = X.shape
    indices = rng.choice(n_samples, size=self.n_clusters, replace=False)
    centroids = X[indices].copy()
    labels = np.zeros(n_samples, dtype=int)

    for _ in range(self.max_iterations):
        # Assignment step
        distances = self._compute_distances(X, centroids)
        new_labels = np.argmin(distances, axis=1)
        if np.array_equal(new_labels, labels):
            break
        labels = new_labels

        # Update step
        new_centroids = centroids.copy()
        for k in range(self.n_clusters):
            mask = labels == k
            if np.any(mask):
                new_centroids[k] = np.mean(X[mask], axis=0)
        if np.allclose(new_centroids, centroids, atol=1e-6):
            centroids = new_centroids
            break
        centroids = new_centroids

    distances = self._compute_distances(X, centroids)
    inertia = float(np.sum(np.min(distances, axis=1)))
    return centroids, labels, inertia, n_iter

Why this design:

  • _compute_distances uses broadcasting: X[:, np.newaxis, :] - centroids[np.newaxis, :, :], producing an (n_samples, n_clusters) distance matrix in one vectorized operation.
  • Convergence is checked both by label stability and centroid movement (np.allclose with atol=1e-6).
  • The best of n_init runs is selected by lowest inertia, mitigating the sensitivity to initialization.
  • Standardization (_standardize) ensures Euclidean distance is meaningful across features with different scales.

api.py — Segment Names & Profiles

SEGMENT_NAMES = [
    "Premium Shoppers",
    "Cautious High-Earners",
    "Impulsive Shoppers",
    "Budget-Conscious",
    "Average Shoppers",
]

def _segment_name(segment: int) -> str:
    if 0 <= segment < len(SEGMENT_NAMES):
        return SEGMENT_NAMES[segment]
    return f"Segment {segment}"

@app.get("/profiles", response_model=ProfilesResponse)
def get_profiles():

    return ProfilesResponse(

        profiles=profiles,

    )

5. Examples & Usage

Training, serving, and consuming the API.

CLI Training

uv run python -m market_segmentation.train --model-dir ./artifacts/models --n-clusters 5 --max-iterations 300 --n-init 10

Python Usage

from market_segmentation.model import KMeans
import numpy as np

X = np.array([[70,85],[80,25],[35,80],[30,30],[55,55]], dtype=float)
model = KMeans(n_clusters=2, max_iterations=300, n_init=10)
model.fit(X)

segment = model.predict(np.array([[60, 60]]))[0]
confidence = model.predict_confidence(np.array([[60, 60]]))[0]
print(f"Segment: {segment}, Confidence: {confidence:.4f}")

REST API Requests

# Single segmentation
curl -X POST http://localhost:8003/segment \
