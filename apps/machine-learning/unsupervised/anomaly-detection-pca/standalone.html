1. Overview & Monorepo Context

Name, purpose, and role within the broader monorepo.

Package name: anomaly-detection (folder: anomaly-detection-pca)
Version: 0.1.0
Purpose: Detect anomalies in server monitoring metrics using PCA reconstruction error. The model learns a low-dimensional representation of normal traffic; samples that reconstruct poorly are flagged as anomalies.

Monorepo role: Lives under unsupervised/ alongside recommendation-engine and market-segmentation. It reuses ai-core for logging, validation, metrics, drift detection, and model registry. Unlike supervised apps, it does not require labeled data for training (only for evaluation).

2. The Mathematical Foundation

PCA via SVD, reconstruction error, and threshold selection.

$$X_{\text{centered}} = X - \bar{x}$$
$$\Sigma = \frac{1}{n} X_{\text{centered}}^T X_{\text{centered}}$$
$$\Sigma v = \lambda v$$
$$X_{\text{reduced}} = X_{\text{centered}} V_k$$
$$X_{\text{reconstructed}} = X_{\text{reduced}} V_k^T$$
$$\text{recon error} = \|X - X_{\text{reconstructed}}\|^2$$

Why this math? PCA finds orthogonal directions of maximum variance. By projecting normal data onto the top k components and reconstructing, we measure how much information is lost. Anomalies lie off the normal manifold and thus have large reconstruction error. SVD is used instead of explicit eigendecomposition for numerical stability. Three threshold strategies are supported: percentile (default 95th), iqr (Q3 + 1.5*IQR), and fixed.

3. Core Logic & Architecture

Data flow, design patterns, and lifecycle.

graph TD
  A[Synthetic / CSV Metrics] --> B[Load normal samples only]
  B --> C[Standardize features]
  C --> D[SVD on centered data]
  D --> E[Select k components by variance ratio]
  E --> F[Compute reconstruction errors]
  F --> G[Fit threshold (percentile/IQR/fixed)]
  G --> H[ModelRegistry.save]
  H --> I[FastAPI lifespan load]
  I --> J[/predict /predict/bulk /stats /model/info]

Design patterns:

  • From-scratch PCA: No sklearn dependency. Uses np.linalg.svd for eigendecomposition.
  • Standardization first: Features are z-scored before SVD so that PCA is not dominated by scale.
  • Anomaly scoring: anomaly_score() normalizes raw reconstruction error into [0,1] using the threshold as reference.
  • Serialization: Stores components, mean, std, variance ratios, threshold parameters, and metadata in a single NPZ.

Primary execution path: train.py:main() → loads data → filters normal samples (y == 0) → fits PCAAnomalyDetector → evaluates on all data (accuracy, precision, recall, F1, FPR) → saves artifacts → registers model.

4. Detailed Code Walkthrough

Key files, classes, and functions.

model.py — PCAAnomalyDetector

def _compute_eigen(self, X_std: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    """Compute eigenvalues and eigenvectors via SVD."""
    n_samples = X_std.shape[0]
    X_centered = X_std - np.mean(X_std, axis=0)
    _, S, Vt = np.linalg.svd(X_centered, full_matrices=False)
    eigenvalues = (S**2) / (n_samples - 1)
    eigenvectors = Vt.T
    return eigenvalues, eigenvectors

def fit(self, X: np.ndarray) -> "PCAAnomalyDetector":
    X = np.asarray(X, dtype=float)
    self.n_features = X.shape[1]
    self.mean = np.mean(X, axis=0)
    self.std = np.std(X, axis=0)
    X_std = self._standardize(X)

    eigenvalues, eigenvectors = self._compute_eigen(X_std)
    self.n_components_selected = self._select_n_components(eigenvalues, self.n_features)
    self.components = eigenvectors[:, :self.n_components_selected]

    reconstruction_errors = self._reconstruction_errors(X_std)
    self._fit_threshold(reconstruction_errors)
    return self

Why this design:

  • _standardize() stores mean and std so they can be reused at inference time.
  • _select_n_components handles both integer and float (variance ratio) specifications.
  • Threshold fitting happens on training reconstruction errors only, preventing data leakage.
  • predict_proba() returns normalized anomaly scores, making the API output interpretable.

5. Examples & Usage

Training, serving, and consuming the API.

CLI Training

uv run python -m anomaly_detection_pca.train --model-dir ./artifacts/models --n-components 0.95 --threshold-method percentile

Python Usage

from anomaly_detection.model import PCAAnomalyDetector
import numpy as np

X_normal = np.random.randn(500, 10)
model = PCAAnomalyDetector(n_components=0.95, threshold_method="percentile")
model.fit(X_normal)

X_test = np.random.randn(10, 10)
errors = model.reconstruction_error(X_test)
anomalies = model.is_anomaly(X_test)
probas = model.predict_proba(X_test)

print(f"Anomalies detected: {int(np.sum(anomalies))}")
print(f"Threshold: {model.threshold:.4f}")
