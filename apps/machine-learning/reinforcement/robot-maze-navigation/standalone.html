1. Overview & Monorepo Context

Name, purpose, and role within the broader monorepo.

Package name: robot-maze-navigation
Version: 0.1.0
Purpose: Train a Q-learning agent to navigate a procedurally generated maze. The agent learns a policy mapping grid positions to actions (up/down/left/right) using temporal-difference learning. Supports both online (environment interaction) and offline (fixed dataset) RL modes.

Monorepo role: Lives under reinforcement/. It depends on ai-core for logging, metrics, and model registry. The app is unique in the monorepo because it requires an environment simulator (maze generation, reward shaping) and exposes a /train endpoint for online training.

2. The Mathematical Foundation

Q-learning, Bellman equation, and temporal-difference learning.

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$
$$Q^\pi(s, a) = \mathbb{E}_\pi \left[ \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \bigg| S_t=s, A_t=a \right]$$
$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$
$$\pi^*(a|s) = \arg\max_{a} Q^*(s, a)$$

Why this math? Q-learning is an off-policy TD control algorithm that learns the optimal action-value function Q* without requiring a model of the environment. The update rule is derived from the Bellman optimality equation. The discount factor γ trades off immediate vs future rewards; α controls learning speed. Epsilon-greedy exploration with decay ensures sufficient state coverage early on while exploiting the learned policy later.

3. Core Logic & Architecture

Data flow, design patterns, and lifecycle.

graph TD
  A[Procedural Maze Generation] --> B[QLearningAgent init]
  B --> C{Mode?}
  C -->|online| D[Interact with env: train_online]
  C -->|offline| E[Load transitions: train_offline]
  D --> F[Q-table update via TD error]
  E --> F
  F --> G[Evaluate success rate]
  G --> H[ModelRegistry.save]
  H --> I[FastAPI lifespan load]
  I --> J[/solve /step /train /stats]

Design patterns:

  • Tabular Q-learning: The Q-table is a 2D NumPy array of shape (n_states, n_actions), initialized with small random values to break symmetry.
  • Dual training modes: train_online() interacts with the maze environment in real time; train_offline() learns from pre-collected transition tuples, demonstrating offline RL.
  • Reward shaping: Positive reward for reaching the goal (+10), negative reward for walls (-5) and time steps (-0.1) to encourage efficient paths.
  • Epsilon decay: epsilon *= epsilon_decay per episode, clamped to epsilon_min.

Primary execution path: train.py:main() → generates maze → creates agent → trains (online or offline) → evaluates policy → saves Q-table and visualizations → registers model.

4. Detailed Code Walkthrough

Key files, classes, and functions.

model.py — QLearningAgent

def update(self, state: int, action: int, reward: float, next_state: int, done: bool) -> float:
    """Perform a single Q-learning update."""
    best_next = np.max(self.q_table[next_state])
    td_target = reward + self.discount_factor * best_next * (1 - done)
    td_error = td_target - self.q_table[state, action]
    self.q_table[state, action] += self.learning_rate * td_error
    return float(td_error)

def train_online(self, env_func, n_episodes: int, max_steps: int) -> dict[str, float]:
    total_rewards = []
    for _episode in range(n_episodes):
        state, goal_positions, maze = env_func()
        state_idx = state[0] * maze.shape[1] + state[1]
        episode_reward = 0.0
        for _ in range(max_steps):
            action = self.get_action(state_idx, training=True)
            next_state = self._step(state, action, maze)
            next_state_idx = next_state[0] * maze.shape[1] + next_state[1]
            reward = self._compute_reward(next_state, goal_positions, maze)
            done = next_state in goal_positions
            td_error = self.update(state_idx, action, reward, next_state_idx, done)
            episode_reward += reward
            state = next_state
            state_idx = next_state_idx
            if done:
                break
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)
        total_rewards.append(episode_reward)
    return {"mean_reward": float(np.mean(total_rewards)), ...}

Why this design:

  • The Q-table is initialized with small random values (rng.uniform(0, 0.01)) rather than zeros to encourage exploration when all Q-values are similar.
  • The TD target includes (1 - done) so that terminal states have no future value.
  • train_offline iterates over fixed transition data for multiple epochs, similar to supervised learning but with TD targets.
  • State is represented as a flat index row * cols + col for efficient Q-table lookup.

data.py — Maze Generation

def generate_maze(rows: int, cols: int, seed: int) -> np.ndarray:
    rng = np.random.default_rng(seed)
    if rows % 2 == 0: rows += 1
    if cols % 2 == 0: cols += 1
    maze = np.ones((rows, cols), dtype=int)

    def carve(r: int, c: int) -> None:
        maze[r, c] = 0
        directions = [(0, 2), (0, -2), (2, 0), (-2, 0)]
        rng.shuffle(directions)
        for dr, dc in directions:
            nr, nc = r + dr, c + dc
            if 0 < nr < rows - 1 and 0 < nc < cols - 1 and maze[nr, nc] == 1:
                maze[r + dr // 2, c + dc // 2] = 0
                carve(nr, nc)

    carve(1, 1)
    maze[1, 1] = 0
    maze[rows - 2, cols - 2] = 0
    return maze

5. Examples & Usage

Training, serving, and consuming the API.

CLI Training

uv run python -m robot_maze_navigation.train --model-dir ./artifacts/models --maze-size 8 --n-episodes 500 --mode online

Python Usage

from robot_maze_navigation.model import QLearningAgent
from robot_maze_navigation.data import generate_maze, get_start_position, get_goal_positions

maze = generate_maze(8, 8, seed=42)
n_states = maze.shape[0] * maze.shape[1]
start = get_start_position(maze)
goals = get_goal_positions(maze)

agent = QLearningAgent(n_states=n_states, n_actions=4, mode="online", seed=42)

def env_func():
    return start, goals, maze

metrics = agent.train_online(env_func, n_episodes=500, max_steps=200)
print(f"Mean reward: {metrics['mean_reward']:.2f}")

path, success, steps = agent.solve_maze(maze)
print(f"Solved: {success}, Steps: {steps}")
