Name, purpose, and role within the broader monorepo.

Package name: semi-supervised-email

Purpose: Classify emails as SPAM or NOT spam using semi-supervised self-training. Only a small fraction of data is labeled initially; the model iteratively labels high-confidence unlabeled samples and retrains, expanding the labeled set without human annotation.

Monorepo role: Lives under semi-supervised/. It depends on ai-core for shared infrastructure. Unlike spam-classification (fully supervised), this app demonstrates how to leverage unlabeled data. The /stats endpoint reports pseudo-labeling progress (n_labeled_history, accuracy_history).

2. The Mathematical Foundation

Self-training, pseudo-labeling, and confidence thresholding.

$$\mathcal{L} = \mathcal{L}_{sup} + \lambda_t \mathcal{L}_{unsup}$$
$$\hat{y}_i = \arg\max_{k} P(y=k \mid x_i; \theta) \quad \text{if } \max_k P(y=k \mid x_i; \theta) \geq \tau$$
$$p_t = \min\left(1, \frac{t}{T_0}\right)$$

Why this math? Self-training iteratively expands the labeled set with high-confidence pseudo-labels. At each iteration, the model trained on labeled data predicts labels for unlabeled data. Samples with probability above the confidence threshold τ are added to the labeled set. The unsupervised loss weight λ_t typically ramps up over time. This approach is particularly effective when labeled data is scarce but unlabeled data is abundant.

3. Core Logic & Architecture

Data flow, design patterns, and lifecycle.

graph TD
  A[Semi-supervised CSV / Synthetic] --> B[Split into labeled + unlabeled]
  B --> C[Train LogisticRegression on labeled]
  C --> D[Predict on unlabeled]
  D --> E{Max confidence >= threshold?}
  E -->|yes| F[Add pseudo-labels to labeled set]
  E -->|no| G[Stop early]
  F --> H{Max iterations or labeled ratio reached?}
  H -->|no| C
  H -->|yes| I[Final retrain on all labeled]
  I --> J[ModelRegistry.save]
  J --> K[FastAPI lifespan load]
  K --> L[/predict /predict/bulk /stats]

Design patterns:

  • Wrapper classifier: SelfTrainingClassifier wraps a base LogisticRegression and manages the iterative pseudo-labeling loop.
  • Confidence thresholding: Only samples where max(proba, 1-proba) >= confidence_threshold are promoted, preventing noisy pseudo-labels.
  • History tracking: n_labeled_history and accuracy_history are recorded per iteration for monitoring convergence.
  • Early stopping: The loop breaks if no confident predictions are found or if min_labeled_ratio is reached.

Primary execution path: train.py:main() → loads semi-supervised data (y=-1 for unlabeled) → fits SelfTrainingClassifier → evaluates on labeled subset → saves model → registers.

4. Detailed Code Walkthrough

Key files, classes, and functions.

model.py — SelfTrainingClassifier

def fit(self, X: np.ndarray, y: np.ndarray, X_test=None, y_test=None) -> "SelfTrainingClassifier":
    X_labeled, y_labeled = self._get_labeled(X, y)
    X_unlabeled = self._get_unlabeled(X, y)
    self.n_labeled_history = [len(X_labeled)]

    for _iteration in range(self.max_iterations):
        self.model = LogisticRegression(learning_rate=0.1, n_iterations=2000)
        self.model.fit(X_labeled, y_labeled)

        if len(X_unlabeled) == 0:
            break

        probas = self.model.predict_proba(X_unlabeled)
        max_probas = np.maximum(probas, 1 - probas)
        confident_mask = max_probas >= self.confidence_threshold
        confident_indices = np.where(confident_mask)[0]

        if len(confident_indices) == 0:
            break

        pseudo_labels = (probas[confident_indices] >= 0.5).astype(int)
        X_labeled = np.vstack([X_labeled, X_unlabeled[confident_indices]])
        y_labeled = np.concatenate([y_labeled, pseudo_labels])

        mask = np.ones(len(X_unlabeled), dtype=bool)
        mask[confident_indices] = False
        X_unlabeled = X_unlabeled[mask]
        self.n_labeled_history.append(len(X_labeled))

    # Final training on all accumulated labeled data
    self.model = LogisticRegression(learning_rate=0.1, n_iterations=2000)
    self.model.fit(X_labeled, y_labeled)
    return self

Why this design:

  • The loop retrains the base classifier from scratch each iteration rather than warm-starting, preventing error accumulation from noisy pseudo-labels.
  • max_probas = np.maximum(probas, 1 - probas) computes confidence for binary classification as the distance from 0.5.
  • Unlabeled samples are identified by y == -1, a convention that allows them to coexist in the same array without a separate mask.
  • The final retrain on all accumulated labeled data ensures the model benefits from the full expanded dataset.

data.py — Semi-supervised Data Loading

def load_training_data(data_path=None, labeled_ratio=0.1, n_samples=1000, random_seed=42):
    X, y_full = _generate_synthetic_emails(n_samples=n_samples, random_seed=random_seed)
    rng = np.random.default_rng(random_seed)
    n_labeled = max(1, int(n_samples * labeled_ratio))
    labeled_indices = rng.choice(n_samples, size=n_labeled, replace=False)
    is_labeled = np.zeros(n_samples, dtype=bool)
    is_labeled[labeled_indices] = True
    y = np.where(is_labeled, y_full, -1)
    return X, y, is_labeled

5. Examples & Usage

Training, serving, and consuming the API.

CLI Training

uv run python -m semi_supervised_email.train --model-dir ./artifacts/models --labeled-ratio 0.1 --confidence-threshold 0.95 --max-iterations 10

Python Usage

from semi_supervised_email.model import SelfTrainingClassifier
import numpy as np

X = np.array([[1,1,1,1,0,8,1],[0,0,0,0,1,2,0]], dtype=float)
y = np.array([1, 0], dtype=int)

model = SelfTrainingClassifier(confidence_threshold=0.95, max_iterations=10)
model.fit(X, y)
print(f"Training mode: {model.training_mode}")
print(f"Final n_labeled: {model.n_labeled_history[-1]}")
